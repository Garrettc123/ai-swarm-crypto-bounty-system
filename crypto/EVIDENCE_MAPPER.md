# ZEUS AutoHunt — authenticated Rust evidence mapper

This is a second-level **passive source review**, layered after the existing
`zeus.py` immutable-source verification and `crypto/autohunt.py` research queue.

## Capabilities

The mapper:

- Reuses the verified five-file Base Everest source receipt; re-fetches each official version-locked file and compares both its Git blob SHA-1 and content SHA-256.
- Authenticates two existing upstream Rust test references (Base transaction RPC and Challenger driver) against fixed Git blob identities at the same competition revision.
- Inventories Rust function declarations and `#[test]`, `#[tokio::test]`, `#[rstest]` declarations through **textual indexing only**.
- Links keyword signal locations to nearby textual function declarations, explicitly not compiler-level ownership or execution coverage.
- Builds a five-question validation backlog with source lines, adjacent test references, and the independent manual scope/known-issues gate.
- Creates `artifacts/evidence-map.json` and `artifacts/EVIDENCE_MAP.md` plus an unsigned SHA-256 metadata-integrity receipt.

All network requests are fixed HTTPS GETs to seven public paths in the exact pinned official competition fork. No live JSON-RPC calls, vulnerability probing, fuzzing, exploitation, devnet startup, external report submission, wallet activity, production deployment, or cloud provisioning occur.

## Reproduce the research step

After creating source review and AutoHunt artifacts with the existing pipeline:

```sh
python3 -m unittest discover -s tests -p 'test_evidence_mapper.py' -v

python3 crypto/evidence_mapper.py \
  --source-review artifacts/base-everest-source-review.json \
  --autohunt-queue artifacts/autohunt-queue.json \
  --output-dir artifacts/
```

This output **does not prove Rust test coverage**, semantic correctness, an exploit, or likely bounty award. Rust tests need a separately qualified isolated Linux runner and scope review; the private runner readiness workflow is in the distinct private control-plane PR. The official immutable competition baseline and permitted **local-only** testing remain controlling.
